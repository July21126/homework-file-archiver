# 作业文件批量归档脚本

批量整理作业文件的小工具，包含三个需求：

## 需求1：扫描与列出
扫描指定文件夹，列出所有文件（大小、修改时间），支持按扩展名过滤。

## 需求2：批量改名
按规则重命名（如 学号_姓名_作业名.pdf -> 作业名_学号.pdf），先预览再执行，处理重名冲突。

## 需求3：归档与报告
按类别把文件移动到子文件夹，生成归档报告，支持撤销操作。

## 运行方式
在 IDLE 中按 F5 运行，或在终端中执行：

# 需求1
python 1.py 文件夹路径 --ext .pdf,.docx

# 需求2（预览）
python 2.py 文件夹路径
# 需求2（执行）
python 2.py 文件夹路径 --execute

# 需求3（归档）
python 3.py archive 文件夹路径 --rules "数据结构:ds,操作系统:os"
# 需求3（撤销）
python 3.py undo archive_manifest.json路径
